Website tugas Case Study 1 — Success Story.

## Struktur
- `index.html` — isi website
- `style.css` — desain website

## Cara upload ke GitHub Pages
1. Buat repository bernama `USERNAME.github.io` (ganti USERNAME dengan username GitHub).
2. Upload `index.html` dan `style.css` ke repository.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`, lalu Save.
6. Tunggu beberapa menit.
7. Buka `https://USERNAME.github.io/`.

Catatan: gambar utama menggunakan URL gambar eksternal. Jika ingin lebih aman untuk jangka panjang, simpan gambar yang memang memiliki izin penggunaan di repository lalu ubah atribut `src` pada `index.html`.
